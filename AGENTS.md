# Instructions for coding agents working on NERVE

Read `START_HERE_CODEX.md` and `PROJECT_CONTEXT.md` before modifying implementation. Run `python -m unittest discover -s tests -q`, the task mini tests and Node chess tests after every relevant change. Keep NERVE local-first and avoid adding mandatory paid/cloud dependencies. Preserve offline operation, project separation, and SQLite data migrations. Any new retrieval method must be compared to a fair flat-search control with held-out questions, ambiguity/abstention tests and source-freshness cases. Never commit `.nerve/`, secrets, local paths, hidden gold answers or generated caches. Do not advertise 100% accuracy or cross-agent productivity gains without new end-to-end evidence. In GitHub releases, verify the remote commit and CI status before saying published. Prefer small, testable pull requests and document evidence for every quantitative claim.
